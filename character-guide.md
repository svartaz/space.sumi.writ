# 實裝時の要望

實裝いただき感謝します.
倫理に反する主張を含まない範圍で いかなる實裝にも喜びます.

各characterの要件は絕對でなく, 好きに改變を加へて下さい (設定者が繪を書けないので明確な基準が有りません).

實裝者には以下を希望します (可能な範圍で).

| 方針                                                                                                      | 避けるべき例                                                   |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 避けるべき例                                                                                              | 黒線, 白拔き, 暈し                                             |
| 法や規約に應じて已む無く性器を汚損する際に, 原本を保存する (制約が解消されたときに原本の提供を依賴します) | 性器を汚損したfileをraster畫像として保存し, 元のfileを破毀する |
| 閲覽者を差別的に制限しない                                                                                | japanese only, 女性向け, 18歲以上のみ                          |
| 閲覽の手順を簡潔にし, 不要なpasswordやclickを要求しない (可達性)                                          | 閲覽したい場合はyesと入力して下さい                            |
| 伏せ字や略稱を使はず, 檢索し易い文字列や一意な識別子 (urlなど) を使ふ                                     | 伏せ字, 繪文字, ‹某キャラ›                                     |
